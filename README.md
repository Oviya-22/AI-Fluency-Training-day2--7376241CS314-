# Day 2 — Agentic AI Foundations and Open-Source Practice Lab

## Objective

This project demonstrates and compares four LLM-based approaches:

- Direct Prompting
- Chain-of-Thought (CoT) Prompting
- ReAct Agent
- Self-Consistency

The project uses Python and the Groq API.

---

## Technologies Used

- Python
- Groq API
- Python-dotenv
- Large Language Model (LLM)
- ReAct
- Chain-of-Thought
- Self-Consistency
- VS Code
- GitHub
